1. Classification Overview

The target is is_churn: 0 means No Churn and 1 means Churn. Logistic Regression is suitable for this binary classification task because it estimates a customer’s churn probability. A probability of {{ results.threshold }} or above is interpreted as Churn.

2. Dataset & Class Distribution

Churn is the minority class, so accuracy alone can be misleading. Precision, recall, F1 Score, and ROC-AUC provide useful evidence about minority-class detection and probability ranking.

Regularization

Logistic Regression has no L1/L2 penalty. Ridge Logistic Regression uses L2 regularization to shrink coefficients, while Lasso Logistic Regression uses L1 regularization and can set some coefficients to zero.

Interpretation

Compare precision, recall, F1 Score, and ROC-AUC together when evaluating churn detection. These metrics make the trade-offs between identifying churners and limiting false alerts visible.
